🔑 Getting Started Checklist

For Beginners

  • Create accounts on ChatGPT and Claude (both free)
  • Install GitHub Copilot if eligible (free for students)
  • Watch intro videos on how LLMs work
  • Practice prompt engineering with simple tasks
  • Read about AI ethics and responsible use

For Intermediate Users

  • Explore different AI tools and compare outputs
  • Learn advanced prompting techniques
  • Use AI for code review and learning
  • Understand AI limitations
  • Join AI communities for updates
